# BNBU Campus Food Map · BNBU 食堂地图

A bilingual (Chinese / English) map of every canteen and food stall on the BNBU campus.
Visitors tap a canteen on a hand-drawn campus map, browse its stalls, and rate them
(1–5 stars, optional comment). Ratings and suggestions are stored by a Flask + SQLite backend.

## Run it locally

Requirements: Python 3.10 or newer.

```bash
python3 -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -r requirements.txt
flask --app app run
```

Open <http://127.0.0.1:5000>. The SQLite database is created automatically at
`instance/campusmaps.db` on first start.

## Project layout

| Path | What it is |
| --- | --- |
| `app.py` | Flask app: page routes and the JSON API (input validation lives here) |
| `database.py`, `schema.sql` | SQLite access (parameterised queries only) and the two tables |
| `places.py` | Loads canteens and stalls from `data/*.csv` |
| `data/canteens.csv`, `data/stalls.csv` | Canteen and stall details — edit these to update the site, then restart |
| `templates/` | Jinja templates: map page, About page (with suggestion form), 404 |
| `static/js/` | `main.js` (wiring), `map.js` (pan/zoom, markers), `panel.js` (place panel, rating form), `search.js`, `about.js`, `api.js`, `util.js` |
| `static/css/` | `tokens.css` (all colours, fonts, spacing), `base.css`, `map.css`, `panel.css`, `about.css` |
| `static/map/campus.svg` | The hand-drawn campus map, generated by `tools/build_map.py` |
| `static/photos/` | Stall photos (file name goes in the `photo` column of `stalls.csv`) |
| `tools/` | Build tools, not needed to run the site (see below) |

## API

| Method & path | Purpose |
| --- | --- |
| `GET /api/places` | All canteens and stalls with average rating and rating count |
| `GET /api/stalls/<id>/ratings` | One stall's rating summary, recent reviews, and the visitor's own rating |
| `POST /api/ratings` | Create or update the visitor's rating `{stall_id, stars, comment}` |
| `POST /api/suggestions` | New stall / correction form `{kind, canteen_id, stall_name, message, contact}` |

Requests carry an anonymous `X-Client-Id` header (a random id kept in the browser's
localStorage). It lets a visitor edit their own rating — one rating per visitor per stall.

## Updating content

* **Stalls / canteens:** edit `data/stalls.csv` or `data/canteens.csv` (UTF-8; Excel opens
  them correctly), then restart the app. `category` must be one of
  `noodles, rice, dumplings, spicy, meals, snacks, fastfood, drinks, other`; set `pick` to `1`
  for "Picks for freshers".
* **Photos:** put a JPEG/WebP (about 1200 px wide) in `static/photos/` and write its file name
  in the stall's `photo` column.
* **New characters in names:** run `python tools/subset_font.py` so the handwriting font
  includes them (needs `pip install fonttools brotli` and the full font in `tools/font-src/`).

## Tools (`tools/`)

| Script | What it does |
| --- | --- |
| `overpass_query.txt` | Overpass API query used to download the campus area from OpenStreetMap (`osm_raw.json`) |
| `build_map.py` | Turns `osm_raw.json` into the layered, hand-drawn style `static/map/campus.svg` |
| `annotate.html` + `annotate.js` | Team-internal page used to mark canteens and stalls on the map (open via `python3 -m http.server` from the project root, then `/tools/annotate.html`) |
| `import_annotations.py` | Converts the annotation export into `data/*.csv` (one-off) |
| `subset_font.py` | Builds the small LXGW WenKai font files in `static/fonts/` |
